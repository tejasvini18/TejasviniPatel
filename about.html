About Me

Quality engineering with an automation-first mindset.

I’m a Quality Engineer with 5+ years of experience across software testing, test automation, software development and security-focused validation. My work combines practical manual testing with maintainable automation, API validation, performance analysis, security checks, database verification and CI/CD quality gates.

Professional profile

From requirements to release confidence.

I translate business requirements and acceptance criteria into structured test strategies, risk-based coverage, reusable automation and actionable defect evidence. I am comfortable working across the test pyramid: unit-level thinking, UI and end-to-end automation, API and integration validation, database checks, regression, exploratory testing and release/UAT support.

My strongest automation focus is modern web testing with Playwright, TypeScript and Python, supported by Selenium, Cypress and established Java/C# ecosystems. I design Page Object Model components, fixtures, test data utilities, assertions, reporting and CI-ready suites with maintainability and deterministic execution in mind.

Quality engineering

Broad coverage, practical execution.

I bring hands-on experience in functional, regression, integration, API, performance and security testing. I use Postman/Newman and REST tooling for API validation, SQL for data integrity checks, JMeter for performance evidence, and OWASP ZAP/Burp Suite for security-focused testing.

I also understand the delivery side of quality: Git workflows, Jenkins, GitHub Actions, Azure DevOps, Docker, Agile/Scrum ceremonies, defect lifecycle management and clear communication with developers, product owners and stakeholders.
